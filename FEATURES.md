## Troubleshooting

**Features not active?**
- Verify RARE-ITEM-SPAWNER folder is in GAMEDATA/MODS/
- Create a new save file for best results
- Restart the game completely

**Crafting popup doesn't appear?**
- Make sure you have nanotubes in inventory
- Hold E key (don't just press it)
- Hover mouse directly over nanotubes

**Game performance issues?**
- Check that all XML files are properly formatted
- Ensure no other conflicting mods
- Lower graphics settings if needed

**Items not showing in crafting menu?**
- Verify CraftingRecipes.xml is present
- Check for typos in file names
- Reinstall fresh from GitHub
