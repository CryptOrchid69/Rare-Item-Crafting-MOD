# RARE ITEM SPAWNER MOD - Installation Guide

## Step-by-Step Installation

### Step 1: Locate No Man's Sky GAMEDATA/MODS Folder
- Open your file explorer
- Navigate to your No Man's Sky installation directory
  - **Default Windows location:** `C:\Program Files\Steam\steamapps\common\No Man's Sky`
  - **Default Epic Games location:** `C:\Program Files\Epic Games\NoMansSky`
- Open the `GAMEDATA` folder
- Open the `MODS` folder inside GAMEDATA

### Step 2: Download the Mod
- Go to: https://github.com/CryptOrchid69/Rare-Item-Crafting-MOD
- Click the green **"Code"** button
- Select **"Download ZIP"**
- Extract the ZIP file to your computer

### Step 3: Add RARE-ITEM-SPAWNER Folder
- The extracted folder should be named `RARE-ITEM-SPAWNER`
- Copy this entire folder into `GAMEDATA/MODS/`

### Step 4: Verify Installation
Your folder structure should look like:
```
No Man's Sky/
├── GAMEDATA/
│   ├── MODS/
│   │   ├── RARE-ITEM-SPAWNER/
│   │   │   ├── MODINFO.XML
│   │   │   ├── CraftingRecipes.xml
│   │   │   ├── README.md
│   │   │   ├── INSTALLATION_GUIDE.md
│   │   │   ├── FEATURES.md
│   │   │   └── [other mod files]
│   │   └── [other mods if present]
│   └── [other GAMEDATA folders]
└── [other game files]
```

### Step 5: Launch the Game
- Start No Man's Sky
- The mod will automatically load when the game initializes
- Works in both single-player and multiplayer modes

## How to Use the Mod

1. **Press TAB** to open your exosuit inventory
2. **Obtain or craft nanotubes** (these are the base item)
3. **Hover your mouse** over the nanotubes in your inventory
4. **Hold down the E key** to open the crafting popup window
5. **Click any rare item** from the list to add it to your inventory
6. **Item appears instantly** - no wait time or material cost!

## Troubleshooting

**Mod not loading?**
- Ensure folder is named exactly `RARE-ITEM-SPAWNER` (case-sensitive on some systems)
- Check that all required files are present in the correct folder
- Verify GAMEDATA/MODS folder path is correct
- Ensure you copied the folder INTO MODS, not created a subfolder

**Game crashes on startup?**
- Remove the RARE-ITEM-SPAWNER folder from MODS and verify the game runs normally
- Check that XML files are properly formatted
- Reinstall mod files fresh from repository

**Crafting popup doesn't appear?**
- Make sure you have nanotubes in your inventory
- Hover mouse directly over nanotubes
- Hold E key (don't just press it)
- Try moving the nanotubes to a different inventory slot

**Items not appearing?**
- Restart the game completely
- Create a new save file
- Verify mod folder is still present in MODS directory

**Multiplayer issues?**
- Verify all mod files are intact
- Restart the game before joining multiplayer
- Check your internet connection

## Multiplayer Mode

The RARE ITEM SPAWNER MOD works fully in multiplayer mode:
- All features remain active when joining multiplayer sessions
- Item crafting works with other players
- Compatible with No Man's Sky's multiplayer system

## Uninstallation

To remove the mod:
1. Delete the `GAMEDATA/MODS/RARE-ITEM-SPAWNER` folder
2. Restart No Man's Sky
3. Game will run with original settings
